# Unique FunPayBot

> Unique FunPayBot — Telegram-помощник для продавцов на FunPay

FunPayBot помогает автоматизировать работу магазина, следить за заказами и сообщениями, управлять лотами и быстро отвечать покупателям прямо из Telegram.

Бот работает 24/7, объединяет более 40 функций и автоматических модулей — продавцу не нужно постоянно держать компьютер включённым.

## Возможности

### Управление магазином

- запуск и остановка бота;
- работа 24/7 без постоянно включённого компьютера;
- поддержание статуса продавца online на FunPay;
- проверка подключения Golden Key и состояния сессии;
- перезапуск фоновых процессов без потери настроек;
- технический режим для временного скрытия управления.

### Лоты и автовыдача

- автоматическое поднятие лотов в поиске;
- настройка интервалов и расписания поднятия;
- создание, редактирование, включение и отключение лотов;
- управление ценами, категориями и изображениями;
- автоматическая выдача ключей, текстов и других товаров;
- контроль остатков и автоматическое отключение лота при их окончании;
- уведомления о низком и нулевом остатке.

### Заказы и покупатели

- уведомления о новых заказах, сообщениях и отзывах;
- быстрые ответы покупателям прямо из Telegram;
- отправка изображений в чат FunPay;
- автоматическое приветствие новых покупателей;
- запрос отзыва после завершения заказа;
- напоминания о подтверждении выполнения заказа;
- просмотр информации о заказе и возврат средств через Telegram.

### ИИ и автоматические ответы

- генерация ответов на отзывы с помощью Groq;
- умные ответы на частые вопросы;
- правила вида «ключевое слово → автоматический ответ»;
- настройка стиля ответов;
- персонализация ответа с учётом оценки, текста отзыва, товара, покупателя и стоимости заказа;
- объяснение функций бота прямо в Telegram.

### Уведомления и мониторинг

Бот уведомляет о:

- новых сообщениях, заказах и отзывах;
- низких оценках;
- поднятии лотов;
- изменении баланса FunPay;
- попытках обращения пользователей из чёрного списка;
- низком или полном окончании запаса;
- ограничениях видимости лотов;
- отсутствии ответа покупателю;
- изменении статуса подписки.

Доступна ежедневная сводка с информацией о заказах, поднятиях и действиях бота.

## Дополнительные модули

| Модуль | Назначение |
| --- | --- |
| **AutoTicket Manager** | Создание обращения в поддержку FunPay, если заказ долго не подтверждается |
| **Auto Refund** | Автоматический запрос возврата при плохой оценке заказа |
| **Auto Report** | Отправка жалоб на покупателей с фильтром запрещённых слов и проверкой ИИ |
| **Auto Send** | Периодическая отправка заданных сообщений в выбранные чаты |
| **AutoGift** | Автоматическая отправка подарков Telegram Stars после оплаты |
| **AutoCopy** | Копирование лотов конкурента на аккаунт продавца |
| **CallSeller** | Вызов продавца по ключевому слову в чате |
| **Auto Rent Steam** | Выдача и продление аренды Steam-аккаунтов |
| **Stock Notifier** | Контроль остатков товаров и отключение лотов при их окончании |
| **SRAS Monitor** | Мониторинг ограничений видимости лотов и требований к рейтингу |
| **Reminder** | Напоминания покупателям о подтверждении выполнения заказа |
| **Status Manager** | Установка собственного статуса для покупателей |

## Безопасность и контроль

- чёрный список покупателей;
- защита от спама;
- автоматическая блокировка за повторяющиеся сообщения;
- гибкие правила автоматических ответов;
- ручное подтверждение для чувствительных действий;
- отдельные настройки для каждого лота и модуля.

## Профиль, статистика и поддержка

В FunPayBot доступны:

- просмотр никнейма, ID аккаунта и текущего баланса;
- статистика работы бота и поднятий по лотам;
- проверка состояния подключения;
- система тикетов поддержки;
- просмотр статуса обращений и быстрые ответы;
- назначение ответственного агента и оценка качества поддержки.

## Для кого подходит

FunPayBot будет полезен:

- продавцам цифровых товаров;
- владельцам FunPay-магазинов;
- продавцам Steam-аккаунтов, ключей и игровых предметов;
- магазинам с автоматической выдачей;
- продавцам с большим количеством заказов;
- всем, кто хочет сократить ручную работу.
